# University of Helsinki: Java Programming II MOOC

Welcome to my repository containing verified solutions for the **University of Helsinki Java Programming II MOOC**, the continuation of [Java Programming I](https://github.com/USAMAKHALIL-1/mooc-java-programming-i). This part covers more advanced object-oriented programming, data structures, and application development in Java.

---

## 🗂️ Progress Tracker

Each sub-folder corresponds to isolated, automated-test-driven (`TMC`) assignments.

- [ ] **Part 8:** Shortcomings of Arrays, HashMap Data Structures, and Generic Analysis
- [ ] **Part 9:** Inheritance, Polymorphism, Interfaces, and Object Reuse Patterns
- [ ] **Part 10:** Language Features, Regular Expressions, Lambdas, Streams, and Files
- [ ] **Part 11:** Class Diagrams (UML), Package Management, Exception Handling, and Runtime Errors
- [ ] **Part 12:** Generic Types, Multidimensional Data Layouts, and Custom Collections
- [ ] **Part 13:** Graphical User Interfaces (JavaFX Event Handling, Visual Layouts)
- [ ] **Part 14:** Data Visualization, Charts, Audio Playback, and Interactive State Controls

For Part 1–7, see [mooc-java-programming-i](https://github.com/USAMAKHALIL-1/mooc-java-programming-i).
